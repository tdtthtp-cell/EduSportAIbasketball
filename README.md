## 📖 1. Giới thiệu tổng quan

**EduSport AI** là hệ thống số hóa tác nghiệp toàn diện dành cho Giáo viên Giáo dục Thể chất và Học sinh trường THPT Huỳnh Tấn Phát. 🎯 **Phân môn mặc định:** **Bóng rổ (Basketball)** — Tối ưu hóa phát triển chiều cao, phản xạ nhanh và tinh thần đồng đội cho lứa tuổi THPT, đồng thời hỗ trợ phân môn Bóng chuyền, Cầu lông, Bóng đá và Đá cầu.

## ✨ 2. Các module tính năng nổi bật

### 🏀 2.1. Phân môn Bóng rổ mặc định & Khung PPCT 70 Tiết
* Toàn bộ hệ thống (Kế hoạch bài dạy, bài tập thể trạng, giáo án minh họa) được thiết lập mặc định theo phân môn **Bóng rổ**.
* Khung Phân phối chương trình (PPCT) 70 tiết chi tiết cho cả 2 học kỳ (HK1: 36 tiết, HK2: 34 tiết):
  - Kỹ thuật di chuyển không bóng, bước trượt, bật dừng 2 bước.
  - Dẫn bóng tại chỗ, dẫn bóng đổi hướng trước mặt (Crossover), luồn hàng cọc zíc zắc.
  - Chuyền bóng 2 tay trước ngực (Chest Pass), chuyền bật đất (Bounce Pass), chuyền trên đầu (Overhead Pass).
  - Ném rổ 1 tay trên vai tại chỗ, ném phạt 4.6m, nhảy ném rổ (Jump Shot) với quỹ đạo Parabol tối ưu 48° - 52°.
  - Lên rổ 2 bước tiếp cận bảng rổ (Layup 1-2).
  - Chiến thuật phòng thủ cá nhân 1-1, bắt bóng bật bảng (Rebound) và thi đấu tập 3x3 trên sân trường Huỳnh Tấn Phát.

### 📝 2.2. Soạn Kế hoạch bài dạy (KHBD) chuẩn CV 5512 & CV 7991/BGDĐT
* Cấu trúc 4 hoạt động bài dạy chuẩn mực:
  1. Hoạt động Mở đầu (Khởi động chung & chuyên môn, đo nhịp tim, phân luồng an toàn).
  2. Hoạt động Hình thành kiến thức mới (Thị phạm mẫu, phân tích động tác, câu hỏi định hướng).
  3. Hoạt động Luyện tập (Tập cá nhân, cặp đôi, nhóm phân luồng trạm, quay video Slow-motion AI).
  4. Hoạt động Vận dụng (Tình huống thực tế, thi đấu tập có điều kiện, hồi tĩnh, bù nước dừa xiêm).
* Tự động tạo và nhúng sơ đồ kỹ thuật động tác sinh cơ học và sơ đồ bố trí đội hình sân bãi.
* Hỗ trợ xuất trực tiếp ra văn bản Word (`.docx`) chuẩn mẫu quy định, font chữ Times New Roman 13pt.

### 🏃 2.3. Phác đồ bài tập cá nhân hóa theo thể trạng BMI
* **Học sinh Thể lực chuẩn (BMI 18.5 - 22.9):** Bài tập cường độ tiêu chuẩn, nâng cao sức bền tốc độ và kỹ thuật khó.
* **Học sinh Thừa cân / Béo phì (BMI ≥ 23.0 - 25.0+):** Phác đồ giảm tải áp lực khớp gối và cột sống trên mặt sân bê tông xi măng; tập ném rổ tại chỗ, bước lướt ngắn, giảm cự ly chạy.
* **Học sinh Thiếu cân / Thể lực yếu (BMI < 18.5):** Tăng cường khối lượng nghỉ giữa hiệp, bài tập tăng cảm giác bóng, tập nhóm đôi tương trợ.
* **Học sinh có tiền sử bệnh nền nhẹ:** Giám sát liên tục nhịp tim, bài tập mô phỏng không va chạm, chuẩn bị bình xịt hen và túi sơ cấp cứu.

### 📊 2.4. Đánh giá thường xuyên theo Thông tư 22/2021/TT-BGDĐT
* Theo dõi tiến độ học tập qua 3 trụ cột:
  - Năng lực kỹ thuật động tác thực hành.
  - Thái độ, ý thức kỷ luật, tinh thần đồng đội và nỗ lực vượt khó.
  - Khả năng ứng dụng công nghệ số (quay video động tác, đo nhịp tim, ứng dụng đếm bước).
* Xếp loại trực tiếp mức **Đạt (Đ)** hoặc **Chưa đạt (CĐ)** theo đúng quy định kiểm tra thể chất hiện hành.

### 🥥 2.5. Chuyên đề Dinh dưỡng học đường địa phương Bến Tre
* Tận dụng thế mạnh nông sản bản địa: Bù khoáng và bù nước điện giải tự nhiên bằng **Nước dừa tươi Bến Tre** sau các tiết học vận động ra nhiều mồ hôi.
* Tư vấn thực đơn dinh dưỡng nông thôn giàu kali, canxi và protein phù hợp điều kiện kinh tế gia đình học sinh.

### 📱 2.6. Cổng tương tác Phụ huynh & Đồng hồ bấm giờ thực hành
* Tạo tin nhắn cập nhật thể trạng, chỉ số BMI và nhận xét tiến bộ gửi đến phụ huynh qua Zalo / SMS.
* Đồng hồ bấm giờ (Stopwatch) tích hợp sẵn hỗ trợ giáo viên kiểm tra thời gian thực hành cự ly, dẫn bóng zíc zắc và đo nhịp tim hồi phục.

## 🛠️ 3. Công nghệ sử dụng

* **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion.
* **Biểu tượng:** Font Awesome 6.5, Lucide React.
* **Xuất tài liệu:** `docx` & `file-saver` (chuẩn Word CV 5512, Times New Roman 13pt).
* **Công cụ xây dựng:** Vite 8, ESBuild.
* **CI/CD:** GitHub Actions (tự động build Vite và deploy lên GitHub Pages).

## 💻 4. Hướng dẫn chạy thử tại máy cục bộ (Local Development)

### Yêu cầu môi trường
* Node.js phiên bản 18 trở lên (khuyên dùng Node.js 20 LTS).
* npm phiên bản 9 trở lên.

### Các bước cài đặt:
```bash
# 1. Clone repository về máy
git clone <URL_REPOSITORY_CUA_BAN>
cd <thu-muc-du-an>

# 2. Cài đặt các thư viện phụ thuộc
npm install

# 3. Khởi chạy máy chủ phát triển
npm run dev
```

Mở trình duyệt truy cập: `http://localhost:3000` hoặc đường dẫn hiển thị trên terminal.

### Đóng gói ứng dụng (Build):
```bash
npm run build
```
Mã nguồn sau khi đóng gói sẽ nằm trong thư mục `dist/`.

## 🚀 5. Hướng dẫn đẩy toàn bộ code lên GitHub (tdtthtp-cell/basketball)

Mã nguồn đã được tối ưu hóa đường dẫn tương đối (`base: './'`) để hoạt động hoàn hảo trên GitHub Pages tại repository:
👉 **[https://github.com/tdtthtp-cell/basketball](https://github.com/tdtthtp-cell/basketball)**

### Các bước liên kết và đẩy code lên:
Mở Terminal tại thư mục dự án và chạy các lệnh sau:

```bash
# 1. Đảm bảo nhánh chính tên là main
git branch -M main

# 2. Thêm hoặc cập nhật remote origin trỏ về repo tdtthtp-cell/basketball
git remote remove origin 2>/dev/null || true
git remote add origin https://github.com/tdtthtp-cell/basketball.git

# 3. Kiểm tra remote đã được cấu hình chính xác
git remote -v

# 4. Đẩy toàn bộ mã nguồn lên GitHub
git push -u origin main --force
```

*(Lưu ý: Nếu GitHub yêu cầu đăng nhập qua terminal, sử dụng GitHub Personal Access Token (PAT) với quyền `repo` và `workflow`).*

## 🌐 6. Kích hoạt Web App trên GitHub Pages (tdtthtp-cell.github.io/basketball)

Sau khi code được đẩy lên `https://github.com/tdtthtp-cell/basketball`:
1. Trên giao diện GitHub của repository, truy cập **Settings** > **Pages** (cột bên trái).
2. Tại mục **Build and deployment**:
   - **Source:** Chọn **GitHub Actions** (không chọn "Deploy from a branch").
3. GitHub Actions workflow (`.github/workflows/static.yml`) sẽ tự động kích hoạt: cài đặt dependencies, chạy `npm run build` và xuất bản website trực tiếp tại:
   🌐 **[https://tdtthtp-cell.github.io/basketball/](https://tdtthtp-cell.github.io/basketball/)**
4. Mọi tài nguyên (JS, CSS, Font chữ, Sơ đồ bóng rổ, Danh sách 225 học sinh) đều tự động tải mượt mà không bị lỗi đường dẫn hay trắng trang.
